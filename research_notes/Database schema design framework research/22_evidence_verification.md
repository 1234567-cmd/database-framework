## Method and limits

- Clients: default curl identity (Git Bash curl 8.8.0, then Windows curl 8.13.0) and WebFetch. No browser-like user agent, cookies, proxies, mirrors or caches. Certificate verification stayed on and `--ssl-no-revoke` was not used.
- No host answered 401, 403, 406, 429 or a bot challenge in this run. Rows marked "refused automated access; needs manual check by the owner" rest on refusals already recorded in the catalog or CORRECTIONS.md; those hosts were not contacted.
- Git Bash curl failed locally with error 43 on many hosts before any HTTP response. Those URLs were fetched with Windows curl. These were client faults, not refusals.
- Four PDF hosts failed curl's revocation check (error 35). Each link retest was run once and recorded as failed. For Codd and PACELC, the PDFs came from WebFetch and text was extracted with pdftotext.
- Matching ran on page text with markup removed, whitespace collapsed and curly quotes normalized. Excerpts are from the served page.
- Result vocabulary: exact wording confirmed; wording differs (short exact excerpt given); not found; refused automated access; needs manual check by the owner; not checked (no openly served source to test).
